# Gate F layered PSD structural preflight

- **Origin:** all layers are purpose-created in test memory; no binary PSD fixture is committed.
- **Owner:** OneClick2D maintainers.
- **Rights basis:** repository-authored deterministic geometric fixture with no third-party source.
- **Allowed use:** repository, CI, documentation, and local disposable PSD structure tests.
- **Content:** small geometric RGBA layers, Unicode names, hidden Read Me, visible semantic layers, generated fill, and hidden locked Source Reference.
- **Generator identity:** `tests/test_gate_f_layered_psd.py` and `spikes/gate_f_runner/acceptance.py`; generated bytes are bound by each bundle index SHA-256.
- **Trademark/likeness:** none.
- **Takedown:** repository maintainers may remove or replace the generated fixtures through normal review.

The writer supports only PSD v1, RGB8, raw channel compression, normal flat raster layers, Unicode names, stable layer IDs, visibility, opacity, and a locked Source Reference. The independently implemented strict reader does not import the writer. ICC embedding and real target-editor open/edit/save evidence remain pending, so this proves only structural readback—not PSD interoperability or Gate F success.
