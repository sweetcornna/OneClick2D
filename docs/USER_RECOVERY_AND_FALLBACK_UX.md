# 用户修正与降级 UX

## 1. 目标

自动初稿出现可恢复缺陷时，用户应理解问题、风险、预计成本和下一步。系统不得用无限重试掩盖不支持输入，也不得把有缺陷结果标成完成。

## 2. `NEEDS_REVIEW`

满足任一非阻塞质量发现时进入 `NEEDS_REVIEW`。界面按部件显示：稳定发现码、影响、证据叠加、安全程度、建议动作、预计时间/资源和是否会改变生成内容。

## 3. P0 修正矩阵

| 问题 | 允许动作 | 修订/验证 |
|---|---|---|
| 输入不适用 | 更换输入 | 新项目源修订，完整重跑 |
| 图层顺序错误 | 选择有限的前后关系覆盖 | 新修订，图环/复合/运动/双导出重验 |
| 蒙版局部漏/多 | 有边界 add/erase brush | 新修订，原始像素/接缝/运动重验 |
| 参数范围不安全 | 缩小安全范围或禁用可选能力 | 新修订，参数套件重验 |
| 可重试生成区失败 | 对登记允许区域重新生成 | 新 attempt + 新修订，完整溯源和受影响验证 |
| 强制能力缺失 | 无静默禁用 | 阻止可用；更换输入/重跑或项目转向 |
| 包/PSD 验证失败 | 无绕过 | 隔离输出，重打包或报告内部错误 |

## 4. 不可恢复情况

安全/解析问题、身份改变的大面积脸部补全、无法保护原始可见像素、非法几何、强制能力缺失、超过 PSD 安全限制、权利或专有格式边界问题必须阻止。界面不提供“仍然下载”。

## 5. 警告确认

确认必须绑定 finding code、instance ID、project digest 和 policy version。修订后旧确认失效。不能用一个项目级 `warningsAccepted=true` 跨修订复用。

## 6. 摄像头与性能降级

权限拒绝、设备缺失、模型加载或性能不足时保留完整手动滑块/预设动作路径。只能在经过验证的情况下降低本地跟踪分辨率/效果；不能上传到服务端作为默认降级。

## 7. 成本与时间

重新生成前显示估计时间、是否消耗配额，以及哪些已批准结果会失效。重复点击使用同一操作 ID，避免重复作业和重复成本。

## 8. 可访问性

所有发现、叠加开关、图层顺序、蒙版工具、范围控制和确认都有键盘及语义控件。画布选择同步提供列表/数值替代；状态不只依赖颜色。
