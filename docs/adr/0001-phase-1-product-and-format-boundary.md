# ADR-0001：一期产品与格式边界

- **状态**：Proposed
- **日期**：2026-07-21
- **Owner / Deciders**：TBD；必须由 Gate 0 具名决定
- **相关记录**：[Gate 0](../gate-records/GATE_0.md)；只有该不可变记录绑定本 ADR 版本并具名批准后，状态才能改为 `Accepted`

## 背景

产品目标常被简称为“一键 Live2D”，但 Cubism 自动导出能力、许可分类、费用、商标和技术路径尚未取得本项目书面确认。直接承诺 `.moc3` 会让核心产品依赖不可控专有边界，并可能诱导逆向工程。

## 决定

1. 使用 OneClick2D 作为未清理的内部代号；
2. 一期生成原创 `.oc2d` 可编辑项目和窄规范分层 PSD；
3. 一期不创建、解析、导入、检查、fixture、逆向或承诺兼容 `.moc3`；
4. 不复制第三方专有标识以暗示兼容，不暗示 Live2D/Cubism 隶属、认可或合作；
5. `.oc2d` 是权威项目，PSD 只是栅格交换；当前章程要求双输出；
6. 对外只能描述“自动 2D 角色初稿”，不宣称专业级或通用成功。

## 影响

优势：技术和许可边界清晰、核心可独立验证、避免专有格式锁定。代价：不能直接满足只接受 Cubism 运行时的用户；需建设自有 renderer/editor；品牌需另行清理。

## Future Gate C

只有获得官方支持能力书面确认、架构分类、许可/费用/再分发/商标复核、法律/商务批准、授权 fixtures、安全/维护预算和独立 ADR 后才可打开。任何批准都不授权逆向工程，适配器必须与 CIR/core 隔离。

## 重新评审触发

官方发布受支持的自动建模/导出接口；商业需求经证据证明；许可或产品策略改变；或双输出章程正式重新立项。
