# OneClick2D 项目章程

- **版本**：0.2
- **日期**：2026-07-21
- **状态**：提议，等待 Gate 0 具名批准
- **项目代号**：OneClick2D（仅限内部，未完成品牌审查）

## 1. 项目假设

对于经过授权、接近正面、单角色、二次元半身立绘，系统可以在一次生成操作后，自动产生可识别、可检查、运动范围受限的 2D 角色初稿，并同时导出可重新打开的 `.oc2d` 项目和窄规范分层 PSD。

该假设尚未成立。必须首先通过 Gate F；不得用手工蒙版、锚点、网格或绑定代替自动路径来宣称成功。

## 2. 目标用户

一期面向受邀请的成年用户：

- 独立二次元内容创作者；
- 需要快速概念原型的小型工作室；
- 愿意检查并有限修正自动初稿，而非要求专业成品替代。

一期采用单账号、单所有者模式。工作室只能通过下载文件交接，不提供共享凭据、角色权限或协作编辑。

## 3. “一键”的定义

“一键”指用户完成上传、单资产权利确认和适用性校验后，只需执行一次“生成”操作即可启动自动流水线。它不表示：

- 任意图片都能处理；
- 无需阅读警告或检查结果；
- 永远无需有限修正；
- 输出等同专业建模师成品；
- 自动生成第三方专有格式。

产品对外描述必须使用“自动初稿”并同时说明输入范围和失败/修正路径。

## 4. 一期范围

### 4.1 输入

- 静态 PNG/JPEG；
- 单个主要角色；
- 接近正面、半身；
- 二次元/动漫绘制风格；
- 眼睛、嘴和主要脸部区域清楚；
- 用户有权上传、临时处理和导出。

具体像素和文件上限是 Gate 1 前的暂定值，不构成公开承诺。

### 4.2 必须输出

成功任务必须同时提供：

1. 经独立验证的 `.oc2d` 自包含项目；
2. 经独立验证的 8-bit RGB/sRGB 分层 PSD；
3. 生成与验证报告；
4. 手动参数预览；
5. 仅在另行通过性能、隐私和授权验证后提供浏览器本地摄像头预览。

`.oc2d` 单独成功不算一期成功；若取消 PSD，必须正式重新立项。

### 4.3 最小修正

一期至少支持：

- 更换输入；
- 安全的图层顺序覆盖；
- 有边界的蒙版增删；
- 缩小或禁用不安全参数范围；
- 对登记为可安全重试的失败区域重新生成；
- 每次权威修改后创建新修订并重新验证。

## 5. 非目标

一期不包括：

- `.moc3` 或其他 Cubism 专有模型输出、解析、导入、检查或转换；
- 全身、侧脸、多人、真人照片或任意画风；
- 专业级顶点、复杂变形器、物理和完整绑定编辑；
- 移动端创作、批量生产、市场、直播插件或计费；
- 永久云素材库、公开画廊；
- 团队邀请、角色权限、评论或并发编辑；
- 离线启动应用、永久服务或无限期格式支持承诺；
- 客户内容用于训练、校准、评估、人工质量审核、演示或营销。

## 6. 产品原则

1. **先证可行，再产品化**：Gate F 失败时停止生产基础设施投入。
2. **ML 提议，确定性代码约束**：模型负责候选，规则负责策略、拓扑、范围、验证和发布。
3. **保护原作优先**：原始可见像素保护优先于运动幅度。
4. **拒绝优于伪成功**：不支持、低置信或不安全时输出明确原因及修正路径。
5. **格式和证据可重放**：项目不依赖重新推理即可打开和渲染。
6. **最少数据**：短期、租户隔离处理；摄像头数据不进入产品服务端。
7. **声明必须可验证**：所有质量、性能、隐私和兼容性说法映射到版本化证据。

## 7. 成功定义

项目成功不是“任务没有报错”，而是：

- Gate F 自动路径通过预注册停止规则；
- `.oc2d` 和 PSD 均能被独立读取、验证和复合；
- 锁定验收集满足 [质量计划](QUALITY_PLAN.md) 的统计规则；
- 目标用户理解边界并能完成检查、预览和双下载；
- 安全、隐私、删除、权利和专有格式边界零硬违规；
- 成本、性能、可靠性和可访问性达到经批准的证据门。

## 8. 停止与转向

满足任一条件时暂停生产化：

- Gate F 未通过；
- 无法取得足够且用途明确的数据或模型；
- PSD 双输出无法稳定实现或缺少编辑器测试权利；
- 核心质量依赖大规模手工修正；
- 人员或 GPU 成本不可持续；
- 关键隐私、安全、品牌或地区法律问题未关闭。

允许转向：要求分层输入、增加用户锚点、改为刚体/仿射剪纸、减少参数、改成引导式生成，或终止项目。转向必须同步修改章程、需求、指标和外部表述。

## 9. 治理

Gate 0 必须任命产品、技术、ML/图形、隐私安全、法律/商务责任人，并批准容量计划。任何人不能单独豁免硬边界。

取消 `.oc2d` 或分层 PSD 任何一个必须正式重新立项并建立新的章程、需求、指标和 Gate 基线，普通 ADR 不能取消。扩大输入或地区、改变客户内容用途、增加第三方专有格式、改变关键质量阈值、改变保留/删除承诺、增加协作/计费/永久存储等其他重大变化必须按影响重新立项或以 ADR 批准。
