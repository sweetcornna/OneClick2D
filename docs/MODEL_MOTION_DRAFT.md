# 模型动态研究初稿规范

- **状态**：Gate F 前可丢弃预研；不是 CIR 或 `.oc2d`
- **固定 profile**：`oc2d.spike.model-motion-draft.affine-semantic.v13`
- **目的**：把受检 See-through 语义层接入确定性四边形、最小参数绑定和共享 37 帧轨迹，尽早暴露真实拆层在运动中的孔洞、接缝和语义错误。

## 输入边界

输入必须是完整通过 `source-preserve.v4` 模型工作台校验的本地运行。生成器只读取清单内的 RGBA 语义层、重建图、模型结果摘要和固定帧序列配置；不调用模型、不读取外网、不修改模型产物。

## 固定能力

研究初稿固定五个参数：`head.yaw`、`head.pitch`、`eye.left.open`、`eye.right.open` 和 `mouth.open`。角色左右按解剖学定义，屏幕左眼映射到角色右眼。所有参数使用共享 Gate F 37 帧序列、线性插值和 clamp 外推。

每个非空渲染部件只生成一个轴对齐四边形和两个正 winding 三角形。面部底层按眼睛、眉毛、鼻子和嘴的语义范围做带羽化的肤色底涂，再由五官图层覆盖，避免模型浅色填充块或连通到外部的眼洞在运动时露出；每只眼睛的眼白、虹膜和睫毛先合并遮罩，再使用原图的真实眼部 RGB 生成单一纹理。眉毛、鼻子和嘴也使用语义 Alpha 限定范围、从原图提取暗色可见细节，不带入模型补全层的浅色填充块。裁切前忽略低于可见阈值的模型噪点，五官使用较强的 Alpha 边缘收紧，其他部件使用轻度收紧。所有部件共享由重建图生成、向内收 2 px 并以高阈值二值化的主体遮罩，只丢弃最外轮廓的背景混合像素，不在语义层接缝处分别收缩；显示级缩放抗锯齿由浏览器基于清理后的主体颜色生成。修复后的裁切图层会随动态报告发布，供离线帧和摄像头预览共同使用。部件边界保留 4 px 安全区，非中性帧使用预乘 Alpha 双线性采样，避免透明 RGB 被插值成暗边或彩边。头部参数使用小范围 shear/translation，后发与面部一起运动以减少头发接缝；眼睛和嘴使用局部 Y 缩放，再与头部变换组合。它不是 mesh-delta、曲面变形或专业绑定。

## 输出与验证

输出目录包含 37 个 RGBA 帧 PNG、`motion-report.json`，以及报告清单中供离线帧与摄像头预览共同使用的 repaired motion-layer PNG。报告固定记录输入摘要、部件/几何/绑定、帧参数、逐帧摘要、全部几何样本的有限性/索引/正面积验证，以及中性帧相对静态重建的 RGB 误差。所有默认参数帧使用同一主体遮罩和外轮廓清理结果，保证中性帧与轨迹首尾像素一致，同时保留实体内部的原图 RGB。

读取器重新计算文件摘要、几何样本和中性帧误差；任何文件、摘要、画布、帧数、参数、引用、索引或验证值不匹配时必须失败。整体质量始终是 `review_required`，且必须保留以下边界：语义正确性、隐藏区域质量和动态视觉质量未评估；只存在 quad/affine research draft；未生成 mesh-delta、`.oc2d` 或 `.moc3`。

## 本地运行

```bash
python -m spikes.gate_f_runner motion --run-id run.local-model
python -m spikes.gate_f_runner gui
```

`motion` 不覆盖已有输出，同一运行只能发布一次受检 motion 目录。GUI 发现该目录后默认打开确定性的“动态初稿”，提供逐帧、滑杆、胶片条和播放；播放前预加载完整帧序列，切帧期间保留上一张已解码画面，避免空白闪烁。输入证据、静态重建和“摄像头驱动”仍可切换，摄像头权限只在用户点击开启时请求。系统启用减少动态效果时禁用自动播放，但保留逐帧检查。

## 摄像头驱动预览

GUI 对存在动态初稿的模型提供“摄像头驱动”视图。浏览器从本地固定资源加载 MediaPipe Face Landmarker `0.10.35` 和 Kalidokit `1.1.5`：MediaPipe 输出 478 点，Kalidokit 的既有 Live2D 求解器输出头姿、双眼开合和嘴部开合，再映射到本初稿的五个受限参数。浏览器按报告中的语义层、bbox、绘制顺序和仿射规则连续合成 Canvas，不用 37 张 PNG 做最近帧跳转。

摄像头必须由用户按钮触发；授权后可在本机视频输入列表中切换设备。页面用低分辨率瞬时亮度统计区分无脸与镜头过暗/被遮挡，统计不保留像素。离开视图、切换运行、隐藏页面或关闭页面时停止媒体轨道。视频帧、关键点、校准值和实时参数只存在于浏览器易失内存，不发送到本地 HTTP 服务、不写文件、不进入报告。MediaPipe、Kalidokit 和人脸模型均固定在同源静态目录，运行时不访问第三方网络。

摄像头合成先在离屏画布完成，再一次性提交到可见画布；短暂跟踪丢失会保持上一姿态，持续 1.8 秒无脸后才平滑回到中性，避免部件回弹闪烁。摄像头预览仍是 `research_draft`：连续浏览器合成不是 mesh-delta、`.oc2d` 或 `.moc3`，也不改变 Gate F、语义正确性、隐藏区域质量或商用准入状态。
