# 隐私、安全与威胁模型

- **状态**：规范性工程基线；法律结论待决
- **批准要求**：任何真实用户上传、新数据流/供应商/用途/地区/保留期之前。

## 1. 硬边界

- OneClick2D 控制的代码不提供接收摄像头帧、裁剪、关键点、嵌入、表达轨迹或校准样本的 API、包字段、日志或遥测路径，也不主动传输或持久化这些数据。
- 客户上传及衍生物不用于训练、微调、校准、评估、产品改进、人工质量审核、演示或营销。
- 艺术内容及内容衍生元数据按敏感内容处理，租户隔离，人默认不可访问。
- 不做公开画廊、公共 bucket、任意 URL 导入、插件执行和永久项目库。
- 分析默认关闭，直到 D-012 记录目的、字段、合法基础、处理者、保留、用户控制和批准。

浏览器、操作系统、驱动、扩展、交换分区和供应商崩溃行为超出产品完全控制范围；对外说明只能承诺应用控制范围内可测试的行为。

## 2. 数据分类与保留

| 数据 | 存储/目的 | 访问 | 期限 | 备份 |
|---|---|---|---|---|
| 隔离上传/标准化源 | 私有临时内容存储 | 任务范围 | 用户删除目标 15m；未完成在 24h 撤销并于 15m 内清空 | 禁止 |
| 图层/补全/网格/项目/PSD | 生成与导出 | 任务/验证器范围 | 成功终态 +24h 撤销，最迟 +24h15m 清空；其他按最早期限 +15m 清空 | 禁止 |
| 内容目录元数据 | 临时目录 | 控制面最小权限 | 随内容删除 | 禁止或经证明加密擦除 |
| 摄像头/跟踪数据 | 浏览器内存 | 本地页面 | 帧/会话生命周期 | 无 |
| 权利确认 | 内容无关审计 | 限定运营/法律 | D-014 决定 | 可按政策 |
| 运行/安全日志 | 内容无关 | 工程/安全 | 暂定 ≤30d | 仅内容无关 |

精确字段、目的、角色、接收者、地区和法律基础见数据处理清单。

## 3. 上传安全

- 认证后创建单次接收、短有效期、服务端生成 opaque key 的上传会话；
- 在供应商支持时固定大小、类型和 checksum，并使用 create-only；
- 隔离、修补、资源受限环境进行 magic 检查和完整解码；
- 拒绝类型不符、多帧、畸形、polyglot、资源炸弹、异常 metadata/profile；
- 应用方向、转 sRGB straight-alpha、移除 EXIF/XMP/IPTC/位置/评论/缩略图/文件名并重编码；
- 模型只能读取标准化副本。

## 4. Worker 沙箱

非 root 临时任务、只读基础镜像、每任务 scratch、无主机挂载/容器 socket/命令拼接，限制 CPU/GPU/RAM/磁盘/时间/输出，默认拒绝出口。短期 job token 只允许精确输入和 attempt 输出。禁止 pickle、脚本、custom op 和外部数据路径。结束/失败/取消清理 scratch，启动时清扫残留。

## 5. 租户和下载授权

服务器从认证推导 account scope，绝不信任客户端 tenant/path/URL。所有项目、上传、任务、attempt、artifact、确认、删除和审计带服务端范围。对 list/get/create/update/delete/download/status/retry/cancel 做正例和双租户负例。

下载使用授权代理，直到供应商证明预签名授予可真实撤销。删除后仍有效的 GET 是发布阻塞问题。

## 6. 浏览器内容与摄像头

- 认证艺术/预览响应使用 `Cache-Control: no-store`；
- service worker、Cache Storage、IndexedDB、localStorage 和 crash payload 不持久化艺术或摄像头数据；
- close/delete 后 revoke object URL、丢弃 buffer；
- 预览源使用严格 CSP，无广告、session replay 或第三方分析；
- 明确 Preview 才请求权限，持续活动指示和 Stop；
- 合成信号变化时监控全部应用源网络/存储/崩溃路径。

用户主动下载的本地文件不受服务端删除控制，界面必须说明。

## 7. 删除

删除 orchestrator：立即 `REVOKED`、fence/cancel 工作，清点隔离源、标准化源、中间层、attempt、缓存、缩略图、导出、multipart、队列引用和供应商副本；执行删除并持续 reconcile；只留下内容无关证明。

数据库恢复必须重放删除墓碑，不能恢复对象引用或内容衍生元数据。任何 incident/legal hold 或异常人工访问必须先由法律/隐私决定、限制权限和期限，并在允许时如实说明；否则保持禁用。

## 8. 日志、支持与管理员

日志和事件采用生产时 schema allowlist；禁止 collect-then-redact、请求体、session replay、像素、文件名、路径、URL、精确艺术摘要、自由文本、任意异常和摄像头字段。

支持无通用像素查看器。若未来批准异常访问，必须 ticket-bound、资源范围、短时、审计和二次批准，并同步更新用户说明。管理员采用 SSO、抗钓鱼 MFA、短期凭据、环境隔离。

## 9. 供应链与权利

所有代码、模型、权重、数据、tracker、PSD 库、字体、服务和测试编辑器记录不可变身份、来源、代码/权重/数据/服务条款、商业/托管/再分发/自动测试权利、安全维护、用途、替换/回滚和下架路径。未知来源、研究/非商用限制或条款冲突阻止使用。

构建固定 lock/digest，产生 SBOM 和 provenance，扫描依赖、容器、IaC、密钥和许可。禁止运行时下载执行 mutable `latest`。

## 10. 主要威胁与测试

| 威胁 | 控制 | 阻塞证据 |
|---|---|---|
| 跨租户/IDOR/陈旧授权 | 服务端 scope、短授权、双租户矩阵 | 任一失败阻塞 |
| 解码器/包 RCE 或炸弹 | 隔离、严格格式和资源限制、fuzz | 崩溃/逃逸阻塞 |
| Worker 逃逸/SSRF | 临时非 root、短 token、无出口 | 沙箱/出口测试 |
| 晚到 attempt 覆盖 | attempt 前缀、所有权/fence、发布验证 | 故障注入 |
| 摄像头外泄 | 无端点/字段、CSP、网络/存储监控 | 任一禁止字节阻塞 |
| 日志泄露 | allowlist、canary 拒绝 | 自动测试 |
| 删除/恢复遗漏 | inventory、墓碑、reconcile、恢复演练 | 任一超时阻塞 |
| 供应链污染 | registry/digest/SBOM/回滚 | 未登记权利阻塞 |
| 权利/冒用 | 单资产确认、报告/下架/申诉 | 外测前准备 |
| 成本/DoS | 认证、CPU 预检、配额、容量预留 | 负载/预算演练 |

## 11. 发布安全门

外部测试前必须：威胁/数据流具名评审；字段级处理清单；无公开存储/广域人工访问；双租户、fuzz、worker、摄像头、日志 canary、删除/恢复通过；无可利用关键/高危问题；全部关键组件权利已知；事故联系人、kill switch 和报告渠道就绪。

本文件不是法律意见。地区、控制者/处理者、跨境、未成年人、面部数据分类、输出权利、AI 透明、通知时限和第三方许可结论由具名法律/商务责任人决定。
