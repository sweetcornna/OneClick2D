# 数据采购与权利计划

- **状态**：Gate 0 阻塞项
- **原则**：数量由具体决策和统计方法反推；权利未知即不可用。

## 1. 必需数据

| 决策 | 最低候选规模 | 必需信息 |
|---|---:|---|
| Gate F | 20 | 扁平图、真实分层、允许研发/评估/内部展示 |
| Gate 2 | ≥60 | group-disjoint、多创作者、完整评分和切片 |
| Gate 3 | 独立验证集；揭盲前按精度/功效目标冻结最小 n 和区间通过规则 | 不用于调参；全部锁定项入分母，missing/timeout/crash/invalid/export failure 为失败 |
| Gate 4 | 100 合格 + ≥100 不合格 | 锁定、重复簇隔离、权利允许发布证据 |
| 补全 | 由遮挡类型和置信目标决定 | 真实隐藏层/运动揭示，不用随机矩形代替 |
| 用户研究 | 提供的批准素材 | 参与者不需上传个人作品 |

训练大规模数据是 aspirational，不是 Gate 0 自动承诺；先根据候选预训练模型权利、Gate F 结果和资金决定。

## 2. 采购方式

优先：目的创建/委托；公共领域；明确授权的数据供应商。每份协议需覆盖具体 train/calibrate/evaluate/display/distribute/derivative/takedown 用途，而不是笼统“AI 使用”。

## 3. 资产台账

每项记录：asset ID、creator/source、合同/权利依据、允许用途、禁止用途、地区/期限、角色/商标/肖像状态、原始/衍生摘要、duplicate family、split、是否可截图/发表、通知/署名、撤回/下架路径、责任人和复核日。

## 4. 合成资产

“合成”不是天然权利依据。记录 generator/version/terms、prompt 和 reference provenance（在安全范围内）、角色/标志/肖像清理、允许用途、近重复检查和 takedown。

## 5. 标注与评审

定义标注单价、吞吐、训练、双标比例、裁决成本和质量抽检。评审者获得合理报酬，协议允许所需评估用途。记录 tool、版本和输出权利。

## 6. 供应商/模型准入

候选模型逐项验证代码、权重、训练数据声明、商业/SaaS/再分发、输出义务、安全、资源和退出路径。条款未知时不得因为技术效果好而试用真实用户数据。

## 7. 时间与预算

Gate 0 给出：每类资产数量和单价区间、创作者/标注者吞吐、合同 lead time、编辑器和存储成本、法律评审、预计重做/下架储备。未获预算时缩小研究问题，而非挪用客户内容。

## 8. 分割与泄漏

按原图、角色、创作者和近重复家族分组；同一来源的 crop、压缩、色变和衍生不能跨 train/calibration/validation/acceptance。锁定集 membership 和标签在冻结后不可因结果修改。

## 9. 停止条件

没有签署的 Gate F 素材、关键模型权利无法确认、无法建立锁定验收集、创作者/标注容量不足或下架无法执行时，停止相应 Gate，不降低证据要求。
